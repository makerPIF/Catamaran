## 1. 선체 설계

쌍동선을 고른 것은 좋은 선택입니다. 동체 두 개가 멀리 떨어져 있어 좌우로 잘 넘어지지 않고,
가운데 데크가 넓어 장비를 얹기 쉽습니다.

| 부위 | 치수 | 이유 |
|---|---|---|
| 동체 길이 | **600 mm** | 길수록 직진성이 좋아집니다. 프린터 베드가 작으면 200 mm씩 3분할 |
| 동체 폭 / 높이 | **90 / 110 mm** | 폭이 좁을수록 물의 저항이 작습니다 |
| 동체 중심 간격 | **350 mm** | 전폭 440 mm. 넓을수록 안정, 좁을수록 회전이 민첩 |
| 데크 높이(수면 기준) | **120 mm** | 파도가 데크를 넘지 않도록 |
| 프로펠러 축 높이 | **데크 +200 mm** | 프로펠러가 물에 닿으면 즉시 파손됩니다 |

### 무게 배분 (목표)

| 항목 | 무게 |
|---|---:|
| 동체 2개 (PETG) | 900 g |
| 데크·연결 빔·마운트·가드 | 500 g |
| 전자부 (ESP32·센서·공유기·카메라·인클로저) | 400 g |
| 모터 + ESC 2조 | 180 g |
| 배터리 3S 5000 mAh | 400 g |
| **합계** | **약 2.4 kg** |

## 2. 부력 확인

물에 잠긴 부피만큼의 물 무게가 부력입니다. 흘수(물에 잠기는 깊이)를 40 mm로 잡으면:

```
동체 1개 : 0.6 m × 0.09 m × 0.04 m × 0.7(선형계수) = 0.00151 m³
동체 2개 : 0.00151 × 2 = 0.00302 m³  →  물 3.02 kg 분량
```

완성 중량 2.4 kg이므로 **흘수는 약 32 mm**, 데크까지 약 88 mm 여유가 남습니다.
장비를 더 얹어도 괜찮다는 뜻입니다.

> 선형계수 0.7은 동체 아래쪽이 둥글게 깎여 있다는 가정입니다. 각진 상자 모양이면 0.9까지 올라가고
> 부력은 더 커집니다. 직접 그린 선형에 맞춰 바꿔 보세요.

## 3. 3D 프린팅 설정

| 항목 | 값 | 주의 |
|---|---|---|
| 재질 | **PETG** | ❌ **PLA 금지.** 여름 햇빛 아래 차 안이나 배 위에서 휘어집니다 |
| 노즐 온도 | 235~245 ℃ | 층간 접착이 방수 성능을 좌우합니다. 조금 높게 |
| 레이어 높이 | 0.24 mm | 0.4 mm 노즐 기준 |
| 벽 두께 | **3겹 (1.2 mm)** | 2겹은 물이 스며듭니다 |
| 바닥 / 윗면 | 각 5겹 | — |
| 채움 | 8 % 자이로이드 | 가볍고 사방으로 튼튼합니다 |
| 출력 방향 | 동체를 **옆으로 눕혀서** | 층이 물살 방향과 나란해져 새지 않습니다 |

## 4. 방수 마감 3단계

1. **이음부 접합** — 3분할 출력물은 다웰 핀으로 맞춘 뒤 30분 경화 에폭시로 붙입니다. 클램프로 눌러 30분.
2. **내부 코팅** — 동체 안쪽 전체에 묽은 에폭시를 붓으로 얇게 발라 층 사이 미세 구멍을 메웁니다.
3. **부력재 충전** — 동체 안에 EPP/EPS 폼을 채웁니다.
   **구멍이 나서 물이 들어와도 배가 가라앉지 않습니다.** 회수 실패를 막는 가장 값싼 보험입니다.

## 6. 펌웨어 업로드

### ESP32 NodeMCU — `firmware/usv_main_esp32/usv_main_esp32.ino`

1. **보드 추가** — 아두이노 IDE → 환경설정 → 추가 보드 관리자 URL에
   `https://espressif.github.io/arduino-esp32/package_esp32_index.json` 입력 →
   보드 매니저에서 `esp32` 설치
2. **라이브러리 설치** — 라이브러리 매니저에서
   `ArduinoJson`, `Adafruit MPU6050`, `TinyGPSPlus`, `ESP32Servo`, `IBusBM`
3. **ZIP 라이브러리 2개** — GitHub에서 [`ESPAsyncWebServer`](https://github.com/me-no-dev/ESPAsyncWebServer)와
   [`AsyncTCP`](https://github.com/me-no-dev/AsyncTCP)를 ZIP으로 내려받아
   스케치 → 라이브러리 포함하기 → .ZIP 라이브러리 추가
4. **보드 설정** — `ESP32 Dev Module` / Flash Size `4MB` / Partition `Default 4MB with spiffs`
5. **업로드** — 진행이 멈추면 보드의 `BOOT` 버튼을 누른 채 기다립니다
6. **확인** — 시리얼 모니터 `115200`에서 Wi-Fi 접속·IP·IMU 보정 메시지 확인

### [카메라 A] XIAO ESP32S3 Sense — `firmware/usv_cam_xiao/usv_cam_xiao.ino`

1. **카메라 결합** — 확장 보드를 "딸깍" 소리가 날 때까지 끝까지 밀어 넣습니다. 절반만 끼우면 초기화에 실패합니다
2. **보드 선택** — `XIAO_ESP32S3`
3. **PSRAM** — 도구 → PSRAM → **`OPI PSRAM`**
   ⚠️ 이 설정을 빠뜨리면 영상이 QVGA 이상으로 안 나옵니다
4. **파티션** — `Huge APP (3MB No OTA/1MB SPIFFS)`
5. **확인** — 브라우저에서 `http://192.168.8.30/stream`

### [카메라 B] ESP32-CAM AI-Thinker — `firmware/usv_cam_esp32cam/usv_cam_esp32cam.ino`

**둘 중 하나만 쓰면 됩니다.** 주소 체계가 같아서 GCS는 고칠 필요가 없습니다.

> [!WARNING]
> **이 보드에는 USB 단자가 없습니다.** USB-TTL(FTDI) 어댑터가 따로 필요합니다.

1. **업로드용 배선**

   | ESP32-CAM | USB-TTL |
   |---|---|
   | `5V` | `5V` ※ 3.3V로 주면 부팅에 실패합니다 |
   | `GND` | `GND` |
   | `U0R` (GPIO3) | `TX` |
   | `U0T` (GPIO1) | `RX` |
   | `IO0` | `GND` ※ **업로드할 때만** |

2. **보드 설정** — `AI Thinker ESP32-CAM` / PSRAM `Enabled` /
   Partition `Huge APP (3MB No OTA/1MB SPIFFS)` / Upload Speed `115200`
3. **업로드 순서** — IO0–GND 연결 → `RESET` 한 번 → 업로드 →
   "Hard resetting..." 이 뜨면 **IO0–GND 분리** → `RESET` 한 번
4. **운용 배선** — `IO0`는 아무 데도 연결하지 않습니다(떠 있어야 정상 부팅).
   `5V`는 UBEC #2에서 받습니다
5. **확인** — 브라우저에서 `http://192.168.8.30/stream`

> [!TIP]
> **외장 안테나로 바꾸면 통달거리가 늘어납니다.** 보드 뒷면 IPEX 커넥터 옆의
> 패드 3개 중 가운데 연결을 PCB 안테나 쪽에서 IPEX 쪽으로 옮기면 됩니다.
> 단, **안테나를 먼저 연결한 뒤 전원을 넣으세요.** 안테나 없이 송신하면 RF 출력단이 손상됩니다.

> [!CAUTION]
> ESP32-CAM은 **전원에 매우 민감**합니다. 5V 2A 이상을 직접 공급하고,
> `5V`–`GND` 사이에 **470 µF 전해 커패시터**를 달아 두세요.
> 이것만으로 "Brownout detector was triggered" 재부팅이 대부분 사라집니다.

> 세 파일 모두 상단의 `WIFI_SSID`, `WIFI_PASS`, `LOCAL_IP`, `GATEWAY` 네 줄만 바꾸면
> 다른 공유기에서도 그대로 동작합니다.

## 7. 조립 순서

전자부를 **먼저 책상에서 완전히 검증**하고, 그 다음에 배에 넣습니다.
배에 다 넣은 뒤에 문제를 찾으면 전부 다시 뜯어야 합니다.

|---|---|---|
| 1 | 선체 출력·접합·방수 | 접착과 코팅 경화에 하루가 걸리므로 가장 먼저 시작 |
| 2 | 책상 위 배선 | 브레드보드에 ESP32·MPU6050·GPS·수신기를 물리고 시리얼 모니터로 센서값 확인. **모터는 아직 연결 안 함** |
| 3 | ESC 3D 모드 설정 | [01-HARDWARE.md §7](01-HARDWARE.md#7-esc를-후진-가능하게-만들기). 프로펠러를 뺀 채로 회전 방향까지 확인 |

| 5 | GCS 연결 시험 | 노트북을 같은 Wi-Fi에 붙이고 `index.html`을 열어 그래프·영상 확인. **여기까지가 "전자부 완성"** |
| 6 | 납땜 정리 | 브레드보드 배선을 만능기판으로 옮겨 납땜, 모든 연결부에 열수축튜브 |
| 7 | 인클로저 수납 | 기판·공유기·UBEC을 넣고 배선은 케이블 그랜드로 빼냄. 뚜껑 둘레에 TPU 개스킷 |
| 8 | 데크 조립 | 알루미늄 각파이프 2개로 좌우 동체를 잇고 데크 플레이트를 M3로 고정 |
| 9 | 모터 타워·가드 | **프로펠러 가드를 먼저 달고** 마지막에 프로펠러. CW/CCW 방향 재확인 |
| 10 | 안테나·카메라 | 마스트에 안테나를 수직으로, 카메라는 선수에서 15° 아래를 보도록 |
| 11 | 배터리 고정 | 벨크로 스트랩으로 데크 중앙 낮은 곳에. 무게중심이 낮고 가운데여야 안 뒤집힙니다 |
| 12 | 무게중심 확인 | 완성된 배를 손가락 두 개로 들어 좌우·앞뒤 균형 확인. 기울면 배터리 위치 조정 |

## 8. 시험 절차

다섯 단계를 순서대로. **앞 단계를 통과하지 못하면 다음으로 넘어가지 않습니다.**

### 0단계 · 시뮬레이션 (권장)

실제 시험 전에 [시뮬레이션 모드](05-SIMULATION.md)로 GCS 조작과 경보 읽는 법을
먼저 익혀 두면 현장에서 당황하지 않습니다. 특히 **전복·통신 두절 상황은 실제로는
일부러 만들 수 없으므로** 시뮬레이션으로만 경험할 수 있습니다.

### 1단계 · 지상 (프로펠러 제거) — 교실 책상

- 확인: 센서값, GCS 연결, 시동/정지, ESC 회전 방향, 페일세이프
- **통과 기준: Wi-Fi를 껐을 때 1.5초 안에 모터가 멈출 것**

### 2단계 · 추력 측정 — 운동장

- 주방저울 위에 배를 고정하고 스로틀별 추력 기록
- 통과 기준: 100 %에서 **1.2 kgf 이상**. BOM의 계산 시트 값을 실측치로 갱신

### 3단계 · 부양 시험 — 큰 대야·수조

- 확인: 흘수, 좌우 균형, 전자부 침수 여부 (모터는 끔)
- 통과 기준: 흘수 40 mm 이하, **30분 뒤 인클로저 내부 건조**

### 4단계 · 근거리 조종 — 수영장·잔잔한 못

- 10 m 로프를 매고 전진·후진·좌우·제자리 회전
- 통과 기준: 모든 방향 제어 정상, 로프 없이 회수 가능

### 5단계 · 통달거리 시험 — 개활 수면

- 50 m씩 늘려가며 RSSI·손실·지연 기록
- 통과 기준: **"주의" 등급이 뜨는 거리를 그날의 운용 한계로 정할 것**

> [!TIP]
> 5단계 시험 데이터를 GCS로 기록해 엑셀로 저장하면 **거리–RSSI 그래프**를 그릴 수 있습니다.
> 안테나를 바꾸기 전후로 두 번 측정해 비교하면 그 자체로 훌륭한 탐구 보고서가 됩니다.
